# Images des newsletters UNAT BFC

Hébergement (GitHub Pages) des images utilisées dans les newsletters « FLASH UNAT BFC » envoyées avec eTarget.

- `commun/` : logos, barre en dégradé, photo du président, icônes des réseaux sociaux (utilisés par tous les numéros)
- `AAAA-MM/` : images propres à un numéro

Adresse publique d'une image : `https://bkcomandmark.github.io/unat-newsletter/<dossier>/<fichier>`

Ne pas supprimer ni renommer un fichier déjà envoyé : les e-mails reçus continuent de pointer vers son adresse.
